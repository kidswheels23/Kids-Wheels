# Kids Wheels — sitio web

Sitio informativo de Kids Wheels construido con React y Vite. Incluye navegación adaptable, preguntas frecuentes interactivas y enlaces a los perfiles sociales proporcionados.

## Ejecutar localmente

Requiere Node.js 20 o superior.

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
npm run preview
```

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub llamado `kids-wheels` (o el nombre que prefieras).
2. Sube el contenido de esta carpeta a la rama `main`, incluyendo la carpeta `.github`.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **GitHub Actions** como fuente.
5. Abre la pestaña **Actions** y espera a que termine el flujo “Publicar Kids Wheels en GitHub Pages”.
6. El enlace público aparecerá en **Settings → Pages**. Para un repositorio llamado `kids-wheels`, normalmente será `https://TU-USUARIO.github.io/kids-wheels/`.

El flujo de GitHub Actions instala dependencias, compila el sitio y publica automáticamente cada nuevo cambio que llegue a `main`.
